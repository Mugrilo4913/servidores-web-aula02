Resumo da Aula
Nesta aula, abordamos os conceitos fundamentais do funcionamento da Web. Compreendemos o papel dos Servidores Web no processamento e entrega de aplicações, a estrutura de comunicação Cliente-Servidor, o ciclo de requisição e resposta (utilizando protocolos como HTTP e HTTPS), e a importância da diferenciação entre ambientes de desenvolvimento (locais) e ambientes de produção (remotos).

 O que aprendi sobre Servidores Web
 Papel do Servidor: Entendi que um servidor web armazena, processa e entrega arquivos (HTML, CSS, JS, mídias) aos navegadores via rede.
 Modelo Cliente-Servidor: Compreendi que o navegador (cliente) dispara requisições e o servidor remoto (como o do YouTube) processa e devolve os dados apropriados.
 Protocolos Seguros: Identifiquei a relevância do HTTPS para garantir conexões criptografadas.
 Ambientes de Trabalho: Aprendi a diferença prática de testar uma aplicação localmente em ambiente de desenvolvimento (ex: com XAMPP) antes de publicá-la em um servidor remoto para acesso dos usuários finais.
