Infraestrutura e Ambientes de Desenvolvimento Web

Conceitos Principais

  • Servidor Local: Um servidor que roda na própria máquina do desenvolvedor (ex: computador pessoal), usado para testes internos sem necessidade de acesso à internet.
  • Servidor Remoto: Um servidor hospedado na nuvem ou em um *datacenter* distante, acessível publicamente ou via rede por qualquer usuário através da internet.
  • Ambiente de Desenvolvimento: O espaço de trabalho isolado onde o código é escrito, modificado e testado pelo desenvolvedor antes de ir ao ar, permitindo cometer erros sem afetar os usuários finais.
  • Ambiente de Produção: O ambiente final do sistema onde o código já testado fica disponível publicamente para ser acessado e utilizado pelos clientes ou usuários finais.

    • Exemplo Prático

    Durante os testes uso o XAMPP no computador (servidor local / ambiente de desenvolvimento). Depois publico o sistema em um servidor remoto para acesso pelos usuários finais (ambiente de produção).
