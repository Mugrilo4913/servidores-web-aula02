Exercício 2

Site Escolhido: YouTube

  • URL acessada: https://www.youtube.com/
  • Quem é o cliente: O navegador web (Google Chrome, Firefox, Edge, Safari, etc.) instalado no dispositivo do usuário, responsável por disparar as requisições HTTP/HTTPS.
  • Quem é o servidor: Os servidores de borda e datacenters da infraestrutura do Google/YouTube, responsáveis por processar as requisições e gerenciar a entrega de dados.
  • Qual resposta o servidor entrega: Código HTML da interface, arquivos de estilização (CSS), scripts de interatividade (JavaScript), metadados de vídeos, imagens de miniaturas (thumbnails) e o fluxo de dados dos vídeos (streaming).
  • Se usa HTTP ou HTTPS: HTTPS (a conexão utiliza criptografia TLS/SSL para garantir a segurança dos dados transmitidos).
